파일 한꺼번에 올리기 — 계획서 PDF · ERP 전표 · CMS 거래내역을 섞어서 끌어다 놓으면 종류와 법인을 내용으로 알아서 나눕니다

모든 파일은 이 브라우저 안에서만 처리됩니다. 계좌 목록·MMT 계좌는 대시보드에 등록된 법인별 계좌를 씁니다.

1. 자금집행계획서 PDF

자금집행계획서 도구에서 만든 계획서를 인쇄한 PDF(4법인 통합) — 원화·외화 블록의 법인별 금액·건수를 읽습니다
자금집행계획서 PDF (4법인 통합) — 끌어다 놓거나 눌러서 선택

2. 법인별 자금집행계획 (확인·수정)

PDF → 자금집행계획서 도구 집계 → 수기 입력 순으로 채웁니다. 값을 고치면 집행일별로 저장됩니다.

3. 법인별 ERP 전표 / CMS 거래내역

칸을 눌러 파일을 고르거나 끌어다 놓으세요. 법인은 ERP '회계단위'·CMS '기업명'으로 판별합니다.
ERP 전표자료조회CMS 거래내역조회

4. 자금집행결과 조회

양식 요약 블록과 같은 구성 · 출금(대변)만 집계
분류 설정 — 타행이체 수수료 · 지출로 볼 자사명 적요
타행이체 수수료는 CMS 자금이동에서 빼고 CMS 지출에 더합니다(자금이동 전표에는 수수료가 없으므로). 공용 저장소에 저장됩니다.
자사명이 들어 있지만 실제로는 지출인 적요 (CMS 구분 → 지출) · 한 줄에 하나

5. ERP 전표 ↔ CMS 거래내역 대사

차이(ERP−CMS) 0이 아니면 빨간색 · 외화 자금이동은 환전 시 차이가 날 수 있어 회색 표시

6. 자금집행계획 ↔ 결과 대사

집행금액(ⅱ) = CMS 지출 + 타행이체 수수료 · 외화는 CMS 외화 이체(USD) · 비고는 차이가 있으면 자동 제안

7. 결과보고서 첨부 계좌

결재 시 은행 거래내역·이체결과를 첨부해야 하는 계좌 (거래 1건이라도 필요면 필요)

8. 보고서 다운로드

내장 양식(결과보고서 시트)에 값만 채웁니다 · 차이·합계는 양식 수식이 계산
